# remindo-data

Remindo অ্যাপের প্রশ্নব্যাংকের অনলাইন কপি (এনক্রিপ্ট করা)। অ্যাপ এখান থেকে সাপ্তাহিক আপডেট নামায়।

- `manifest.json` — সংস্করণ, তারিখ, পরীক্ষা/প্রশ্নের সংখ্যা, চেকসাম
- `questions.bin` — সব প্রশ্ন
- `x.zip` — সব ব্যাখ্যা
- `img/` — অ্যাপ বানানোর পরে যোগ হওয়া ছবির প্যাক
- `images_index.txt` — যেসব ছবি আগেই প্রকাশিত

প্রতি সপ্তাহে ফাইলগুলো বদলে দিলেই হয়; `manifest.json` সবার শেষে আপলোড করুন।
